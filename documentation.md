# Aura Accessibility Project

## Research Phase

Before starting the project, I spent time researching accessibility-focused websites and modern landing page designs. My goal was to understand how websites can be designed to help users interact with digital content more easily.

I explored different examples of accessible user interfaces and learned about the importance of clear layouts, readable typography, color contrast, and simple navigation. I also reviewed HTML and CSS concepts that would help me create a clean and responsive design.

During this phase, I collected ideas and planned the structure of my website before starting the implementation.

## Implementation

After completing the research phase, I began building the Aura project using HTML and CSS.

I first created the main structure of the webpage and then designed the hero section, which introduces the purpose of the project. After that, I added buttons, headings, and descriptive text to improve the user experience.

To make the website more professional, I worked on styling elements such as colors, spacing, alignment, and typography. I also added additional sections to provide more information about the project and create a more complete landing page.

Throughout the development process, I continuously tested the design and adjusted the layout to improve readability and visual appearance.

## Finishing Phase

Once the main development work was completed, I carefully tested the website and reviewed all sections to ensure that everything displayed correctly.

I fixed small design issues, improved the structure of the page, and verified that all files were properly connected. After confirming that the project was working as expected, I uploaded it to GitHub using Git version control.

This allowed me to store the project online and keep track of all changes made during development.

## Problems and Solutions

### Problem 1: CSS Changes Were Not Applied Correctly

At one stage, some styling changes did not appear on the webpage as expected.

**Solution:**
I checked the file paths and verified that the CSS file was correctly linked to the HTML document. After correcting the connection, the styles were applied successfully.

### Problem 2: Learning Git and GitHub

Since Git and GitHub were new tools for me, I initially found it difficult to understand the workflow of adding, committing, and pushing files.

**Solution:**
I practiced using Git commands, followed documentation and tutorials, and gradually became more comfortable with the process. This helped me successfully upload and manage my project on GitHub.

### Problem 3: Improving the Overall Design

The first version of the webpage looked very simple and lacked enough content.

**Solution:**
I enhanced the design by improving the layout, adding more sections, refining the styling, and creating a more organized structure that better represents the project.

## Conclusion

This project helped me strengthen my understanding of HTML, CSS, Git, and GitHub while also introducing me to important accessibility concepts in web development.

Through planning, development, testing, and documentation, I gained practical experience in creating a complete web project from start to finish. The final result is a clean and accessible landing page that demonstrates both technical and design skills while highlighting the importance of accessibility in modern web applications.
