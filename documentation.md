# My First Project

## Research Phase
At the beginning of the project, I searched for information about HTML, CSS, Git, and GitHub. I learned how to create a simple web page and how to use Visual Studio Code for coding.

## Implementation
I created a web page using HTML with headings and paragraphs. After that, I used CSS to improve the design, change colors, and make the page look cleaner and more organized.

## Finishing Phase
After finishing the coding part, I tested the website in the browser to make sure everything worked correctly. Then I uploaded the project to GitHub using Git commands such as git add, git commit, and git push.

## Problems and Solutions
One problem I had was that the CSS changes did not appear in the browser. I solved the problem by refreshing the page and checking that the CSS file was connected correctly to the HTML file.

Another problem was using Git commands for the first time, but after practicing the commands several times, I understood how they work.

## Conclusion
This project helped me understand the basics of web development and how HTML and CSS work together. I also learned how to use GitHub to save and manage projects online.
